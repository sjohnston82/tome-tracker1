# Metadata review center

Open Library → Review metadata (`/library/review`), or follow the link from Series import notes. The page separates source conflicts, uncertain edition matches, unconfirmed series positions, and optional missing details. Category/state/search filters cover the whole queue; Show more expands the first 30 displayed items. Missing details are suggestions, not errors. Historical Read books are not asked for invented completion dates, and intentionally blank locked covers are preserved.

Import conflicts are recomputed from the saved manifest and the current library, so corrected discrepancies leave the queue automatically. Side-by-side values show source file, sheet/row and series context. Keep library value records an acknowledgment without changing metadata; Reviewed lets the user reopen it. Decisions are tied to the relevant source/current values, so meaningful changes reopen the question while an unchanged import rerun does not. Reopen tombstones are merged by review timestamp, preventing older reviewed reports from resurrecting dismissed decisions.

Use source value requires a separate confirmation and changes only the displayed field. Publication years may also be entered manually after verification. An active reading session blocks source reading-status changes; the book’s reading tracker remains the place to finish or revise that session. No action fabricates reading dates, deletes logs, or silently changes covers, authors, titles or ownership. Unowned series work years remain work metadata and never create physical books. Recorded series positions/types can be confirmed; unknown positions must be edited in Series.

Import previews are saved as CollectionImport staging records (`tome-collection:preview`), without creating or changing books or works. This keeps ambiguous source matches available after navigating away. Selecting an existing candidate requires confirmation and pins only its empty/same source identity; a record already assigned to another source row cannot be taken over. Import matching respects COLLECTION_IMPORT_ENABLED. Re-preview the same manifest in Series before applying. Successful application retires only a matching staged preview and carries review decisions forward. Import notes remain historical provenance rather than pretending every old warning is still open.

Decisions live inside existing import report JSON and are included by the current backup/restore format. No database migration, new dependency, production operation or background metadata lookup is required. Missing-field suggestions and series confirmations use existing records; imports/source files are not rewritten. Invalid saved manifests produce a visible review question and do not erase live catalog data.

GET /api/metadata-review is authenticated and private/no-store. PATCH accepts only a review item ID, its current version, an allowed action, and any required verified year or candidate ID. Targets and proposed values are rebuilt server-side from the signed-in account. Serializable transactions with retry, version checks and conditional writes reject stale reviews and identity races. All book, work, series and import reads/writes are owner-scoped. Account-switch and offline handling prevent stale private queues or mutations from being presented as another account’s results.

Validation: local TypeScript and 296 unit/component tests passed. Added PostgreSQL tests cover keep/reopen persistence across reruns and backup restore, exact-field updates with preserved reading logs/cover locks, stale/foreign decisions, staged ambiguous editions, and work/series changes without ownership changes. HTTP tests cover authentication, private responses, rendering, and keep/reopen/apply actions. Database/HTTP validation runs in CI’s disposable PostgreSQL environment; no local library records were changed during development.
