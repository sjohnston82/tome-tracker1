# English cover preference

Automatic representative artwork prefers an English edition rather than the first work-level jacket. Open Library search uses `lang=en` and requests nested edition cover/language fields. The query contains the title alone: forwarding author terms can leave the nested edition list empty even when the work matches. Automatic selection checks the returned title and every author locally (including shared surnames). British/American colour/color fallback remains supported. Search requests up to 20 work candidates and ranks confirmed English above unknown-language artwork.

A work’s language list describes its translations and cannot identify its generic cover. Use the selected edition’s cover and language. Known non-English representative covers are skipped. Generic work artwork remains a fallback only when edition data is entirely absent; if edition data is present but supplies no eligible cover, leave the cover missing. Unknown language cannot guarantee an English cover.

Exact ISBN lookup resolves `/isbn/<isbn>.json`, verifies that the record lists the ISBN, and uses that physical edition’s cover. It does not substitute a generic work jacket or force an English translation onto a known foreign-language ISBN. Scan/ISBN metadata behavior likewise stays edition-specific. General Open Library search uses the selected edition’s title and cover together and returns an ISBN only when it is present on that selected edition; work-level ISBN lists must not attach a different translation’s ISBN to an English jacket.

The manual cover picker sorts exact ISBN matches first, then English, unknown language and other languages. Other-language alternatives remain selectable from Open Library; grid captions show language names or “Language unknown.” Open Library language keys/ISO three-letter codes and Google language codes are normalized before ranking. Google cover/general text searches request `langRestrict=en`; exact Google ISBN lookup is unrestricted. All Google Books lookup paths now attach GOOGLE_BOOKS_API_KEY when configured server-side, including the general search/ISBN provider. The optional variable is documented in .env.example.

The preference applies to new/missing artwork and future searches. Existing covers are not rewritten, and the existing cover locks and conditional missing-cover writes continue to preserve manual choices. No migration is required. Provider language metadata can be incomplete or inaccurate; the cover picker remains the way to confirm artwork against a physical copy.

Regression tests cover a German work jacket with an English edition, English-over-unknown ranking, foreign-only/empty edition data, verified ISBN precedence, title/author validation, coherent edition cover/ISBN metadata, language-ranked manual alternatives and Google’s key/language parameters. A live public Open Library query for East of Eden confirmed that the generic and English-edition cover IDs differ and that title-only querying returns English edition details where author-filtered queries do not. No user library records or credentials were used in the live check.

## Recovery after live missing-cover failures

Live verification after clearing automatic covers exposed two gaps: Open Library expansion can take 6–7 seconds (longer than the original 4.5-second timeout), and its nested edition data may be empty or contain no cover. A configured Google Books key now enables a fast English-volume lookup before title-based Open Library searches. Unknown-language Google results wait until Open Library has been tried; known foreign-language title matches are rejected. Exact ISBNs try the physical Open Library edition first, then an ISBN-verified Google edition, without a language filter. No anonymous Google calls are made when the server key is absent.

Open Library searches now allow 10 seconds and fetch five candidate works including their validated work keys. If a matched work has no usable English search-edition cover, the first 100 actual work editions are checked (8-second timeout) for an English cover. Source titles with a leading The/A/An and author Jr./Sr. suffix differences are handled without editing saved metadata. Google queries use the first coauthor for retrieval and validate every coauthor before accepting the result. Returned artwork URLs remain limited to known provider hosts.

Each lookup has a shared 25-second provider budget. Cover batches process two books to fit that combined budget inside the 60-second route limit, including spelling retries. The endpoint permits 30 batches/minute, maintaining the previous maximum of 60 books/minute. Cursors continue beyond unmatched books, failed providers still produce error counts, and manually locked covers remain protected by conditional writes.

A live two-book batch saved covers for The New Spring and Welcome to the Monkey House with zero errors. The image endpoint returned a nonempty JPEG with HTTP 200. Locked cover URLs and total library count were verified unchanged. Regression tests cover fast keyed Google results, foreign/provider-failure fallback, a six-second Open Library response, missing search-edition expansion and the smaller batch/cursor behavior.

## Titles, subtitles and split volumes

Automatic matching now compares provider titles together with their separately stored subtitles. Explicit Part/Pt. and Volume/Vol. numbering accepts canonical Roman or Arabic numerals; standalone Roman words are unchanged. Split-volume Google retrieval uses the parent title to avoid an over-restrictive quoted query, but selection still requires the full requested physical title and every author. Open Library requests edition subtitles and chooses a matching edition rather than the first English jacket. Parent works can lead to edition enumeration, but a whole-book or different-part cover cannot replace a requested split volume. Unknown edition titles are rejected for split-volume requests. Exact ISBN verification and manual cover locks remain unchanged.

Regression fixtures include The Reality Dysfunction, Part 1: Emergence and Van Loon's Geography: The Story of the World, with separately stored subtitles, Roman part numbering, wrong-part and wrong-author alternatives, and actual edition expansion.

Live read-only lookup confirmed automatic cover results for both example titles: Open Library edition cover 286907 for Emergence and a Google Books cover for Van Loon’s Geography. No library data was changed by these checks.
