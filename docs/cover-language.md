# English cover preference

Automatic representative artwork prefers an English edition rather than the first work-level jacket. Open Library search uses `lang=en` and requests nested edition cover/language fields. The query contains the title alone: forwarding author terms can leave the nested edition list empty even when the work matches. Automatic selection checks the returned title and every author locally (including shared surnames). British/American colour/color fallback remains supported. Search requests up to 20 work candidates and ranks confirmed English above unknown-language artwork.

A work’s language list describes its translations and cannot identify its generic cover. Use the selected edition’s cover and language. Known non-English representative covers are skipped. Generic work artwork remains a fallback only when edition data is entirely absent; if edition data is present but supplies no eligible cover, leave the cover missing. Unknown language cannot guarantee an English cover.

Exact ISBN lookup resolves `/isbn/<isbn>.json`, verifies that the record lists the ISBN, and uses that physical edition’s cover. It does not substitute a generic work jacket or force an English translation onto a known foreign-language ISBN. Scan/ISBN metadata behavior likewise stays edition-specific. General Open Library search uses the selected edition’s title and cover together and returns an ISBN only when it is present on that selected edition; work-level ISBN lists must not attach a different translation’s ISBN to an English jacket.

The manual cover picker sorts exact ISBN matches first, then English, unknown language and other languages. Other-language alternatives remain selectable from Open Library; grid captions show language names or “Language unknown.” Open Library language keys/ISO three-letter codes and Google language codes are normalized before ranking. Google cover/general text searches request `langRestrict=en`; exact Google ISBN lookup is unrestricted. All Google Books lookup paths now attach GOOGLE_BOOKS_API_KEY when configured server-side, including the general search/ISBN provider. The optional variable is documented in .env.example.

The preference applies to new/missing artwork and future searches. Existing covers are not rewritten, and the existing cover locks and conditional missing-cover writes continue to preserve manual choices. No migration is required. Provider language metadata can be incomplete or inaccurate; the cover picker remains the way to confirm artwork against a physical copy.

Regression tests cover a German work jacket with an English edition, English-over-unknown ranking, foreign-only/empty edition data, verified ISBN precedence, title/author validation, coherent edition cover/ISBN metadata, language-ranked manual alternatives and Google’s key/language parameters. A live public Open Library query for East of Eden confirmed that the generic and English-edition cover IDs differ and that title-only querying returns English edition details where author-filtered queries do not. No user library records or credentials were used in the live check.
